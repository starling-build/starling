**Rule (fits all 37 Word prints within 0.15 pt, every step right):**
1. List the table's possible cuts, as heights from its top: every row boundary, and, inside a row that can split, after k text lines. A cut inside a row leaves a part of max(row minimum height, k lines) + 0.5 border.
2. Each cut c gives a candidate top `C = H - 0.34 - c` (H = page height): the top at which that cut lands on the page EDGE.
3. Take the smallest candidate with `top margin + bottom margin <= C <= tblpY`, i.e. the most table above the edge. If there is none, the table lands at `tblpY`.
   Same thing read another way: lift the table so that a cut lands exactly on the bottom margin, as high as the top margin allows, then set it down by the bottom-margin height.
4. Then split as usual at the bottom margin. A row splits only if the part left on the page is at least the row's minimum height, and its remainder on the next page keeps that minimum (61.34 here).
