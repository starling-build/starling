**Where.** RichLayout+Paginate.swift, in the `newPage()` block that follows the two moves `page-anchored-table-taller-than-a-page-goes-whole-to-the-next-page-...` and `page-anchored-table-whole-goes-to-the-next-page-...`. A table that starts on its own page is not lifted: Word keeps gridlift tblpY 105/120 at tblpY on page 1, although a cut is available.

**Inputs** (content coordinates, y = 0 at the top margin):
- `target`: the existing tblpY - insetTop.
- `pageBottom = _px(pageSetup(forPage: physical).height) - insetTop`, as in `page-anchored-table-set-up-to-the-page-edge`.
- `floor = bottom margin` (`_px(pageSetup.marginBottom)`). Word's lowest allowed top is top margin + bottom margin, which is `floor` in these coordinates.
- The table's rows from `_cells` (`rowTop`, `ownRowHeight`), each row's stated at-least height `ts.rowHeights[row]`, `cantSplit`, and each cell's line bottoms (`_lineBottoms(geometry(k).painter)`).

**Cut search.**
1. Build a list of cuts, as heights from the table top:
   - every row end: `rowTop + ownRowHeight - c0.rowTop`;
   - for every row that can split (not cantSplit, not an exact height), every line bottom `b` of its cells, at `rowTop + max(at-least height, b + cell bottom padding) - c0.rowTop`. A part is never shorter than the row's at-least height.
2. Each cut gives a candidate top `yc = pageBottom - cut - rule`. Take `rule` from the page-edge branch: `max(c.ruleBelow, ruleUnder(c))`. In the labs this puts the rule of the cut 0.46 pt above the page edge.
3. Keep the candidates with `floor <= yc <= target`. If any are left, set `y = min(kept)` (the most table above the edge). Otherwise leave `y = target`.
4. Then lay out and split as now, at the bottom margin. Do not split at the edge: the lift only picks the top.
No per-pitch or per-margin constant. Pitch enters only through the row heights.

**Split rule to check while there** (seen in every gridlift print): a row splits only if the part left on the page is at least its at-least height plus the rule (61.35 here). Otherwise the whole row goes on. Its remainder on the next page also keeps that minimum (61.34). If ours differs, fix that in the same PR, because the lifted tops depend on it.
