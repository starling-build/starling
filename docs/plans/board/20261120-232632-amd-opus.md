# RULE amd-opus, puzzle 11 (xd b88f2314, 55680978): the bullet cell's last 8 pt is dropped by the "next row" contextual rule, which should not fire in a cell merged down

**What the labs lacked:** the bullet cell (row 0, col 3, vMerge restart, vAlign center) is merged down over row 1. Its last paragraph is a List Paragraph (contextualSpacing) with `w:spacing after=160` (8 pt). In document order the paragraph after it is row 1's FIRST cell (Normal, "(고용주 명)" column), so `nextRow(i + 1)` in `_spacing` (RichLayout+Paginate.swift, the lab-rk rule "Word takes a contextual paragraph's space after away before the next ROW's paragraph") fires and drops the 8 pt. But that row-1 paragraph stands BESIDE the merged cell, not under it. Word keeps the 8 pt in the centred content. lenovo-2's labs had no merged cell, so this never fired there.

**Measured (trace of the centring step, flow units / 20 = pt):** our centred content 178.41 pt = 12 before + 7 paragraph heights, with the last bullet's height (32.14) holding no space-after. Word's print fits plain centring of the same paragraphs WITH the 8 pt.

**Fix (tried locally, not landed):** in `nextRow`, `return a.table == b.table && b.row >= a.row + a.rowSpan` (was `b.row > a.row`). That is: the next row's paragraph counts only when it is in a row below the end of the cell's merge. Result on b88f2314: content 178.41 to 186.41, the bullet block moves up exactly 4.0 pt. Measured from the cell's top border, the first bullet then sits 39.84 pt down against Word's 37.44, and the ~2.1 pt of that is half the cell-height gap of my build. Net error inside the cell is about 0.3 pt.

**Caveat:** my engine is from 11-06, so the whole table and pages 5-7 drift in my render (unrelated to this, and not a tip regression I can vouch for). Measure the before/after on a current build. In a96b8a4aa the cell is also 0.84 pt taller than Word's and its top border is 0.72 low (header-row rules; see 4e1fdb8fe, which round 498 bisected as a drop of this doc from 167 to 135 lines). After this fix, expect the bullets about 1 to 1.5 pt low on the tip, not 5.5. That rest is the row height, not centring.
