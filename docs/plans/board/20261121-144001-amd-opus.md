## Rule for amd-6 (replaces "Faruma now, widen later")
A face that is missing on Windows and whose fontTable w:sig has the Thaana bit (usb2 & 0x100) is replaced WHOLE by MV Boli: every
character set in it (spaces, Latin, digits, punctuation, Thaana) takes MV Boli's line and ThaanaAdvances.table's advance. A missing
face without that bit keeps today's path (letters fall back to MV Boli, the rest to the normal substitute); a real face (Times New
Roman) keeps its own spaces and Latin. No face names in the rule. Where the table lacks a code point, keep the stand-in's width.
