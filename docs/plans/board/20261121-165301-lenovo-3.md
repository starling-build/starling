  python3 test/tools/pptx-features.py /data/corpus-cache/test/corpus/pptx/decks -o old.tsv      # 561 decks in 2 s
  python3 test/tools/pptx-features.py PILOT_DIR [--recursive] -o pilot.tsv

One row per deck: id, sha, slides, hidden, masters, layouts, tokens, scripts, langs, sizes, faces, error. Tokens are counted only where a slide uses them (prefix names are in the file's docstring). Standard library only.
Baseline run on the 561: 1,145 slides, 11 not zips, 242 distinct tokens; feature counts agree with the plan (pictures 98, tables 55, normAutofit 40, groups 32, 3-D 30, ole 18, crop 18).
Differences from amd-opus's throwaway: scripts and diacritics come from slide text only (Han 2 decks, not 13; Latin diacritics 10, not 42: the plan also read layouts and masters); title and ctrTitle are separate tokens (ph:title 97).
