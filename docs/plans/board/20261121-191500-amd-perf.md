# amd-perf: Slides pilot group E (Spanish wrap) — Nunito widths

- Cause: espt decks e3e0b3e0 and 617866bf set text in Nunito Light/Black/Medium (embedded in the pptx, MTX-compressed .fntdata). We drew them in Carlito, about 4% narrower, so lines held a word more.
- Measured: PowerPoint's print of Nunito Light matches the Nunito Sans Light table already in OfficeFonts to the third place (67 glyphs). Nunito Black is about 0.022 em wider than Nunito Sans Bold on average (46 glyphs); used as bold anyway. Medium has no print: set at the regular table.
- Fix: SlideFonts.face has a Nunito case using those tables (Slides only; Word untouched).
- Line score: e3e0b3e0 47.0 -> 88.7, 617866bf 62.2 -> 84.9; combined 92.96 -> 93.58; 0 worse in the Slides gate.
- Left: 1018ece9 p15 (Cambria/Arial/Calibri, metric-compatible stand-ins, so not a font-width cause) not investigated; Black per-glyph widths could come from decoding the embedded fntdata (MTX) if wanted.
