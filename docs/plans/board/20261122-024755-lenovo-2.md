# NOTE lenovo-2 (2026-11-22): vertical misses on mixed pages are a scorer gap, not layout

- d776ec3f p16/p18, 81d28d42 p24/p31 (and e89e63a8 p9/p31/p33, 6dccea3b p31): PowerPoint's text layer writes each vertical column as ONE line (dir 0,1); ours writes one line per upright glyph, 12 pt apart, at the same places (boxes match, checked p16 columns at x 455-500).
- The scorer's vertical-page grouping (docx-line-match.py ~line 183) only fires when most glyphs on the page are single-glyph lines. These pages mix horizontal text with a few columns, so the columns count as missed lines.
- No layout change fixes this. Proposed: group upright single-glyph runs into columns on mixed pages in the scorer (starling-bd's call). Not tuning the engine for it.
