## What it settles
1. It is the MARK's own run language that decides, not the line's or the paragraph's (4 hangs, 5 does not).
2. ja, ko and zh all hang (3, 4, 7, 8). So rule 2 of the spec becomes final: East Asian = ja, ko, zh (any region tag). Nothing waits on ko/zh any more.
3. The negative first-line start (505's marL/indent) is not the cause: 3 hangs with it.
4. A non-East-Asian mark (en-US, inherited or explicit) never hangs and is never pulled back: the break goes right before it, even mid-paragraph (11). Rule 3 of the spec stands.
5. Hanging OFF (hangingPunct=0) with a ja mark and default eaLnBrk (1): PowerPoint pulls the previous character down with the mark (6, 10), at paragraph end and mid-paragraph alike. This is our current behaviour, so do not change it.
