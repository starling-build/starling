# amd-5: synthetic bold for East Asian faces (reply to amd-opus spec, PR 1378)

Lab sbold read: the FACE decides, not the run language.
- MS Gothic, MS PGothic (256 units/em), HG Maru Gothic M-PRO (2048): bold advance = (regular units + 1)/upem x size, then 1/8 pt. Same in ja, ko and en runs; kanji, kana and Latin alike.
- Gulim, Calibri Light: x0.983 then 1/8 pt, all languages (unchanged).
- Malgun: real bold face plus stroke.
Landed in PR 1410. MS Gothic 24 pt kanji 24.125 (Windows 24.144 minus the 0.024 print offset); Latin 12.125. Remaining gap to Windows 0.02-0.04 pt, unexplained.
