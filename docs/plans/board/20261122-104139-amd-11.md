## Rig table: how a face normal becomes a shade (Extrusion.lit, Extrusion.swift ~line 197)
- Input: face normal n, base colour, rig table (front RGB factors + 4 wall rows (r,g,b,white)), turn (deg).
- lean = |nz|/|n|; w = sqrt(1 - lean^2) (0 = face looks at the viewer, 1 = a wall).
- front-facing: k = front factors; back (nz<0): k = darkest wall.
- wall factor: azimuth a = atan2(ny,nx) - turn; wall(a) = c0 + c1 cos a + s1 sin a + c2 cos 2a, fitted to the 4 wall rows (0,90,180,270 deg). Clamp at 0.
- shade = w * wall(a) + (1 - w) * front, per channel; colour = base * shade (+ whiteShare of the 4th number as highlight, PROVISIONAL).
- So a CHART column face: top = normal (0,0,1) -> front factors; side walls -> wall(a) by the face azimuth. Use Extrusion.lit(base, n, rig: Extrusion.rigs[name], turn:) with the same n; do not hard-code 0.88.
- Measured table exists only for legacyFlat3 (front 0.757, walls 0.60/0.60/0.84/0.60). Legacy-camera path takes the table only for legacy* light rigs (PR #1553, fixed after the gate showed oox-Scene3d_lightRig_legacyCamera 0.49->1.23 when twoPt was caught too).
