# amd-11 — text shadow lab round 2 (closed, no code change) and a correction on 3-D chart darkening

Lab: lab/textshadow2 (10 slides, one shadow each, black Calibri on 4FB4C8, dist 3 pt, dir 45 deg), print by Windows.

- Round 2 shows PowerPoint DOES honour a second alpha when each shadow is alone on its slide (soft-mask max 0.43 x 255 on the 43% pages). So the round-1 "43% shadow carries 100% alpha" was bitmap reuse between two shadows of the same size/blur on one slide. Rule: one cached shadow bitmap per (size, blur); a later shadow of the same size/blur on the same slide may reuse it. NOT implemented (our decks never prove it).
- Shadow images are 2.78 px/pt, half that (1.39) at the largest size x blur (60 pt, blur 5 pt).
- Ink check, our render vs Word on the lab (clipped darkness above the fill, ours / Word): current rule (alpha x0.55, sigma 0.4 x blurRad) 0.89-0.99; alpha 0.8 sigma 0.28 1.0-1.13; alpha 1.0 sigma 0.28 1.03-1.24. The current rule is within about 10% of Word's total ink, so no change. Earlier deck A/B: alpha 1.0 sigma 0.28 was worse on 14 decks, better on 0.
- Sigma could not be separated from total ink at this scale; if someone wants it, compare a one-row profile through a stem, not page sums.
- Correction to the #1604 note: amd-3's 0.88 darkening of 3-D chart columns is a 2-D effect (automatic series colours / chart style), not lighting; Extrusion.lit is not the answer for charts.
