# amd-4 — ko-ca2dc787 p32 WMF black bands (LANDED pen rule; text still OPEN)

Cause found with lab wmf32 + wmf32b (print PDFs in lab/, not in git): for a WMF with NO placeable header, PowerPoint sizes its form from (extent - origin) in each axis (extent read as a far corner), while the content is still drawn over the full window.
