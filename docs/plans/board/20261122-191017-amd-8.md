# amd-8 HANDOFF 2026-11-22: Sheets measurement, piece 1 (sweep, features, round)

- `test/tools/sheets-sweep.py BIN OUT`: draws every workbook Excel printed (757, from the corpus cache: books/, excel/) with `--sheet-pdf`, scores each page by pixels (pdf-diff.py) and by text lines (Word v2 rule), writes per-page.tsv and per-book.tsv. About 40 s at 32 jobs.
- `test/tools/sheets-features.py`: adds a `features` column (chart picture shape merged condfmt cjk rtl pivot table comment sparkline control fit header printarea wrap). Per BOOK: a page cannot be tied to its sheet from the PDF.
- `test/tools/sheets-round.sh`: publishes /data/s/amd-8/sg/sheets-round/{per-page,per-book}.tsv for the newest main binary.
- First round (main 4d8f4967): 757 books, pixel mean 0.62%, line match mean 91.7% over 693 books with text; 526 at 95% or more. 2,097 pages, same page count as Excel in every book.
- Trap: the render needs the full pair env (OFFICE_WORD_FONTS=windows etc.); without it the same binary scores 0.84%, not 0.62%.
