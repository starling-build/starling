# amd-opus SPEC (puzzle 15, from amd-6): Slides 2007-style charts, value-label stand-off with and without a legend; 3-D columns

**Answer 1: PowerPoint uses ONE rule, with or without a legend. The "-2.5" is ours, not PowerPoint's.**
Our working area starts 6.5 pt inside the frame for a chart with `c:style` + chart-wide text (the three corpus decks) and 9 pt inside otherwise (amd-6's lab charts have no `c:style`). 9 - 2.5 = 6.5. So the lab formula is right for the lab only because it cancels our 9.

Measure from the FRAME, not from `area`:
- Widest value label (or bar name) starts at frame left + 6.5. Five witnesses: lab 51.5 (frame 45); line, scatter and bar decks 126.5 (frame 120); 5864 slide 8 (titled column chart, legend right, 16 pt bold) 18.5 (frame 12).
- Plot left = that label's right edge + 0.927 x size. Lab 6 pt 63.1, 18 pt 86.4; line/scatter decks 152.3; bar deck 199.7 (names end 183.1); 5864 p8 46.4 (labels end 31.5, 0.927 x 16 = 14.8). All within 0.1.
- So: plot.left = frame.left + 6.5 + widest + 0.927 x size, for legend or none, title or none. Drop `!c.legend` and the -2.5 on the left side.
- Bottom (horizontal bars), same story: value-label baseline = frame bottom - 8.0 / 9.1 / 11.2 at 6 / 10 / 18 pt (text bottom 6.5 inside the frame, Calibri descent 0.25 x size), plot bottom = baseline - 1.59 x size. Lab 18 pt 374.6 / 345.9 (frame 385.8); bar deck 418.8 / 390.1 (frame 430): identical offsets. The 0.4 miss on the deck is again our area (foot 6.5 against 6.9).

**Right edge: one limit R that the last label may not pass; plot right = R - how far the last label sticks out past the plot** (0 for columns and lines, half the last value label for bars and scatter, half the last name for area).
- No legend: R = frame right - 11.0. Lab, frame right 671.85: column plot 660.8; bar "10" ends 660.9; scatter "7" ends 660.9; area "F" ends 660.9. So "11.1" and "1.9 further left for bars" are the same edge.
- Legend at the right: R is set by the legend, not the frame. Legend text ends 10.0 inside the frame in all four decks. From the legend text's left edge T: square or marker key, R = T - 32.7 at 18 pt (bar "10" and scatter "5" both end 520.3, T 552.9) and T - 35.0 at 20 pt (5864 p8 column plot 575.8, T 610.8; a titled column with a legend has NO extra inset). Line key: R = T - 36.9 (plot 516.0). The line chart's extra 4.2 is its longer key (19.2 pt against a 9.9 pt square; it starts 6.8 further left), not a plot inset and not the title.
- Our old legend numbers already give these edges, so keep the old right edge when there is a legend. Only the left and the bottom need unifying.
- Not measured: legend at bottom, top or left; an axis title on the label side. Limit the rule to legend none or right until a print shows the others.

Extra: tick marks are 0.317 x the axis label size long, not a fixed 5.6: 1.9 / 3.2 / 5.7 at 6 / 10 / 18 pt (lab), 5.1 at 16 pt (5864 p8). The stand-off is label to axis line, so this only moves the drawn tick.

**Answer 2 (3-D columns): the label rule is the same; our 3-D BOX is in the wrong place.**
The print is not only a raster: the front axis line and the floor line are vector paths (pdf-probe draws, lg2 pages 10-12).
- Label right edge to the front-left axis line: 5.6 / 9.4 / 16.7 at 6 / 10 / 18 pt = 0.927 x size. Ticks 1.9 / 3.2 / 5.7 again.
- PowerPoint's axis x: 77.5 / 82.8 / 93.9. Ours: 73.7 / 75.8 / 79.8, with a fixed 9.1 gap. That is the whole 7.3 / 6.7 / 6.5.
- PowerPoint's box, frame 45 to 671.85: front face 77.5 to 600.5 (6 pt), back wall right edge 645.2 / 645.7 / 645.9 = frame right - 26.3, which is 15.3 further in than a flat chart. Depth shift: across = 0.0855 x front width (44.7), up = 0.140 x front height (34.3). Top as a flat chart (81.8 / 82.0 / 86.8). Floor 359.0 and category baseline 374.9, both 1.8 higher than the flat chart's 360.8 / 376.7.
- Ours: back wall right edge 658.8 (13 inside the frame), so our box is 17 pt too wide: 13.5 at the right, the rest at the left.
- The labels are NOT flush at frame + 6.5 here: "10" starts at 65.8 / 63.3 / 58.9. Fit on these three pages: axis x = frame left + 24.3 + 1.367 x size (misses 10 pt by 0.2).
- NOT PROVEN: whether 1.367 x size is label width or label size. Every page uses the label "10", so width and size move together. Use the fit only for the right edge (frame right - 26.3, solid on 3 pages) until a lab splits them.
- Lab that settles it (one round, 6 slides): the same 3-D column at 10 pt with value formats "0", "0.00", "#,##0.000" (width only changes); the same three at 18 pt; plus one at half the frame width. Read axis x and back-wall right edge with pdf-probe draws/images.
