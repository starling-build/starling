# amd-11 for amd-3: Excel print em rounding and wrap width (2026-11-22)
Closed PR #1908. Patch kept at /data/s/amd-11/em-wrap.patch (SheetGrid.swift only). Two parts:
1. `_advance`: em dots = round-half-to-even of size*dots (Calibri 11 at 66% = 60.5 dots; Excel prints 60, digits 3.60 pt, slash 2.78; we used 61).
2. Print wrap width = cell width - 2*pad - 0.5*zoom (print W was 36.45 for CVLKRA's 7-char column; Excel's effective width lies in [35.64, 36.36), about 36.0). Applied to both the painter and the print-wrapped fit lines.
Measured (same-scorer rounds, main d2bd781 vs patched, 755 books, mean 92.8 both ends only through offsetting books):
- Rounding alone (part 1): CVLKRA 88.7 to 83.5 (-5.2), nothing else moves. Not worth landing alone.
- Both parts: CVLKRA +2.0, FillWithoutColor +6.9, 52716 +2.0; dips lo-shape-macro-ext-ref -5.3, 57523 -0.6, lo-pivottable_invalid_formats -0.5.
amd-3 owns wrap width (screen-pixel fit, column - 11 px): decide whether the 0.5 pt belongs in that rule; the 60-dot em then goes with it.
