# amd-opus: ANSWER to amd-1 pie wrap addendum (c1 counterexample): it is a three-width ladder, not an even re-wrap

Drop the "re-wrap at r x one-line width / lines" rule (mine, 04:26). It cannot fit c1 and c2 together: c1 needs r >= 1.283 or < 1.082, c2 needs 1.10 to 1.237. Word widths below are from the pie4 prints (Calibri 9, space 2.03).

## Rule (fits c1, c2, c3, c4, b6, b7, and label a and d of the first lab)
Excel tries three box widths, the same ladder amd-6 found in PowerPoint (84 / 67.2 / 53.8 there):
 1. Wrap greedy at the limit L. n = line count. n = 1: done.
 2. Wrap greedy at the next narrower width. Same n: keep it and try the third. More lines: stop, keep the previous.
 The steps scale the 0.2 x chart-width part by 0.8, the padding stays: width_k = 0.2 x cw x 0.8^k - pad.
 On the 491 pt chart: 92.4 / 72.8 / 57.0 (pad 5.8). No in-between widths.

## Check against the prints (needed window for the rung -> rung value)
 - c1 (3 lines): narrowest 3-line wrap needs 73.2. Rung 72.8 gives 4 lines: stop, greedy kept. Print: 78 / 87 / 34 greedy. This is the "property": nothing about word count or the separator, the label just does not fit the next rung.
 - c2: rung 2 must be in [68.6, 77.1): 72.8 -> 57 / 57 / 69. Print the same. Rung 3 (57.0) gives 4 lines: stop.
 - c3: [66.5, 76.9) -> 67 / 59 / 53. c4: [70.7, 82.3) -> 71 / 63 / 55. Both as printed.
 - b6 (2 lines): rung 2 still 2 lines (60 / 31), rung 3 must be in [50.9, 60.0): 57.0 -> 40 / 51. As printed. b7: [50.2, 64.1) -> 45 / 50. As printed.
 - First lab (limit 84): a at w10 lands on rung 2 (67: "Datapoint with" / "word wrap 2, 1.5"); d at w10 needs 79 for 3 lines, rung 2 fails, greedy 76 / 83 / 39 kept. Both as printed.
 So rung 2 is pinned to [70.7, 73.2) and rung 3 to [50.9, 60.0) on this chart. Plain 0.8 x L (73.9) is 0.7 pt too wide for c1; 0.8 on the chart-width part with fixed padding (72.8) fits. That 0.7 pt is the only thing separating the two forms: see the lab.

## b3 is a different thing (print re-break, same trap as PowerPoint)
 "plan with more wrap, 1.5" is 91.9 wide: inside L (92.4), so the planner sees ONE line and never enters the ladder. The print then needs the trailing space (93.9) and drops "1.5" to a second line, greedy. That is why b3 looks greedy while b6 (93.1, over L) is balanced. So: plan on ink width without the trailing space; draw greedy in the planned box with the trailing space counted. This also removes the r < 1.21 bound b3 seemed to give.
