## Lab (needed, one round): kn-room
One xlsx, built like the book: default font Calibri 12, no dyDescent marker, no stored row heights, every test cell wrapText, left, Arial 12 unless noted.
- One sheet per string. Columns B..U (20 columns), widths stepped 1 px: column px = W + 5 + 4 ... W + 5 + 23, width attribute = (px - 5) / 8. W = the string's whole GDI extent in Nirmala UI 12 at 96 dpi.
- The string goes on the diagonal (B2, C3, D4 ...), one cell per row, so each row height is one cell's fit.
- Read each row's height (COM Rows(r).RowHeight after open, and the print). The first column where the row is one line gives pad = px - 5 - W.
- Strings:

## How to read it
- pad equal on S1..S5 and above the Latin pad: rule 1 (a fixed room cut for complex text). S7 says whether it is Indic-wide; S6 whether it is linking.
- pad grows with the word count (S5 > S3 > S2 = S1): rule 2; the step per word is the number.
- pad follows the spaces (S5 > S3 = S4 > S1 = S2 by 4 and 7 spaces): rule 3. S3 against S4 isolates the comma.
- pad grows with W (S1 small, S2 middle, S3 large): rule 4, then the fix is real screen advances, not the room.
- S8/S9 not at 9: our Latin pad is off in a Calibri 12 book, and Kannada is not special.
