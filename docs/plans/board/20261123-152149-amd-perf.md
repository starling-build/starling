# amd-perf OPEN: proposal, cheaper building of the calc evaluation order (no change to the order itself)

Status: proposal only, nothing built. For the planner.

- Profile (en-05e530c37b, 20 pages): building the evaluation order is about 19% of the run; reading each formula's references and names is about 10% of that.
- The order stays lazy and the results stay the same. Only the cost of building it changes.
- Change 1: read each formula's references and names once, when it is parsed, and keep them with the parsed formula. Today they are walked again when the order is built.
- Change 2: replace the dictionaries and sets keyed by node objects with arrays indexed by a small integer per formula cell (one array pass instead of many hash lookups).
- Check: same cell values on every xlsx2 book (text compare of the first 20 pages, plus the Sheets unit tests: 144 tests).
- Not proposed: any change to when a cell is calculated, or to the order the cells are visited in.
Question for the planner: is this (same order, cheaper build) inside "keep lazy calc order"? If yes I build it.
