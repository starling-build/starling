# amd-4 HANDOFF: .doc tables whose rows have different column edges (2026-11-23)
Bug: the .doc reader took the table grid from the FIRST row only and gave later rows no gridSpan, so a row with fewer/wider cells (a form with merged rows) put its cells in the first columns: squeezed text, overlapping rows (ko-0a01d04622, pt-b6ede5e037 10 pages squeezed into 1 column strips).
Fix: rows are collected per table; if the rows do not share edges (and share the left edge), every row is stated against the union of all edges (snapped 3 twips) with gridSpan. Rows with a different left edge keep the old path.
Check (same binary A/B, 318 dev .doc): 30 docs change page count, 317 convert (the encrypted one is refused). Seen: pt-b6ede5e037 10 to 1 page, a full form; ja-233ec9bff0 now a proper grid. No Word prints yet to score.
