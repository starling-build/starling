## bulpitch (Symbol bullet line pitch, Ubuntu / Calibri / Arial, 1.0, 1.15, 1.5 lines, bullet same size or 8 pt)
- Calibri and Arial: ours matches Word's three-line block pitch (Plain B, Bullet A, Bullet B, Plain C) to 0.1-0.2 pt for every block.
- A bullet line stands taller than a plain one by (Symbol ascent 1.004 em) minus (text ascent incl. line gap): Arial +0.78 pt, Calibri +0.66, Ubuntu cloud +0.54 per bullet line at 12 pt. This fits Word's print.
- Ubuntu with a same-size bullet: ours is 0.2 pt per bullet line too tall (block 29.0 against Word 28.6, 33.2/32.8, 42.8/42.5). With the 8 pt bullet it matches exactly. Cause not found: likely our Ubuntu text ascent sits 0.15 pt (0.0125 em) under Word's cloud-font ascent+gap. Small; no dx2 doc picked for it.

## carry2 (top-and-bottom box anchored at 14.15 pt, thin 0.5 pt, in the first line)
