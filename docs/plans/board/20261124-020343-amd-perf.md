# amd-perf: layout proxy writes copied whole arrays (bug65649 258 s to 53 s)
- Cause: the _ParaFrame / span-frame proxy properties (`var x { get { rl.x } set { rl.x = newValue } }`) had no `_modify`, so every `_cells[i] = ...` or `_floatImages[i] = ...` copied the whole array out, changed one element and wrote the whole array back. 30 % of bug65649's time was that copy.
- Fix: add `_modify { yield &rl.x }` to all 80 proxy properties (two files). No behaviour change.
- Measured, 8 jobs, 767 Word docs, same box: all 767 PDFs byte-identical with the fix and without. CPU 2,164 s to 1,869 s. bug65649 275 s (hits the 300 s limit) to 70 s. Next slowest doc is 24 s.
- Trap: a computed property proxy over a stored array needs `_modify`, or each element write is O(n).
