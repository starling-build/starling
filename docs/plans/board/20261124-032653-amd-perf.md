# amd-perf HANDOFF: .doc toggled character flags (0x81)

In a .doc, a character flag (caps, bold, italic ...) stored as 0x81 means "the opposite of what the style gives". The reader wrote it as plain "on". So a footer in a caps style, where the run toggles caps, was drawn in capitals (Word draws it in lowercase). Now the reader settles each toggle against the paragraph style chain and writes an explicit on or off.
