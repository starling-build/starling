# amd-perf: .doc default tab stop (DOP dxaTab)

The .doc reader ignored the DOP's default tab stop (dxaTab, byte 10 of the DOP, twips), so every .doc used 720. Spanish and Portuguese Word writes 708 (35.4 pt). es-7289450bf2's four leading tabs stood 2.4 pt too far right, so "nuestro" wrapped to line 2; page 1 now matches Word.
- The reader writes a settings part with only the tab stop; Docx.swift reads a settings part holding nothing but defaultTabStop as no settings (a plain settings part flips the East Asian and compat defaults: tried, mean 51.3 to 48.8, ja/ko -89).
