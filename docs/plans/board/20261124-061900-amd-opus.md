# amd-opus ANSWER for lenovo-2: Slides, theme MS PGothic first baseline (lab num2 vs deck 5c820695)

Short answer: MS PGothic's own share is 36/256, as the lab says. The 52/256 is not a face property. It is what a line gets
when it holds the PARAGRAPH MARK and the mark's Latin face is not the Japanese face. Deck 5c820695 is all one-line
paragraphs (every line holds a mark, Latin = theme Calibri); the lab's first lines are first lines of long paragraphs.

## The rule (PowerPoint print)
The line stays 1.2 em. Only the baseline inside it moves.
For the faces on a line, INCLUDING the Latin face of the paragraph mark on the paragraph's last line:
  A = 1 - (smallest descent share), D = largest descent share, baseline = line top + 1.2 em x A / (A + D).
(Each face counts as a 1 em cell split by its descent share; highest ascent and deepest descent win; the 1.2 em line is split in that ratio.)
One face alone gives the old rule 1.2 x (1 - share). The mark's face is its endParaRPr Latin face, else the last run's Latin face.

Examples, Japanese share 36/256 = .1406:
- mark in Calibri (.2200): 1.2 x .8594/1.0794 = .9554 em (alone: 1.0313). This is the "52/256" (.2038 x 256 = 52.2).
- Palatino Linotype (613/2763): .9537. Century Gothic (451/2440): .9876. Arial (434/2288): .9831. Same face as the text: 1.0313.

## Evidence
1. Lab num2, every box: first line 1.031 em at every face (HGS Mincho E, MS PGothic, MS Gothic). The LAST line of each
   paragraph is lifted, and the next line is late by the same amount (pitch 1.125 then 1.275 em), so the 1.2 em grid holds.
   Lift in pt, rule vs print (the print moves in 0.12 pt steps):
   24 pt: Calibri 1.82 vs 1.80; Palatino 1.86 vs 1.80; Century Gothic 1.05 vs 0.96.
   18 pt: Calibri 1.37 vs 1.44; Palatino 1.39 vs 1.44; Arial 0.87 vs 0.95; Century Gothic 0.79 vs 0.84.
   Box E (Latin face = HGS Mincho E, same as the text): no lift at all.
2. Deck 5c820695: all 12 top-anchored MS PGothic first lines sit at .954-.960 em (mean .9555; rule .9554), sizes 28-44,
   placeholders and text boxes alike; every one is a one-line paragraph. Same slide 14, same size, same box top:
   "検索" (theme faces) .959, the box whose runs AND endParaRPr name HGPGothicE as Latin 1.037.
3. All 41 Japanese pptx-full decks, top-anchored MS PGothic first lines: the values fall in two groups at the same sizes
   (16 pt: 7 at .955, 8 at 1.04; 18 pt: 10 and 2), so size is not it. The 1.03 group is multi-line paragraphs
   (64f938d1 p17, theme Calibri, .. 1.0315) or Latin face = the Japanese face (+mn-ea, +mj-ea, a theme whose Latin IS MS PGothic: c8c1c343).

## What to change
- ownDescentShare "ms pgothic": back to 36/256 (with MS Gothic). Drop the 5c820695 comment.
- Line baseline: apply the A/D rule per line, adding the mark's Latin face on the last line of each paragraph.
  This is by property (faces on the line), so it also covers MS Gothic, HG faces, and any Latin face.
- Expect: lab num2 boxes B/C first lines 1.031 and their last lines lifted; 5c820695 unchanged where it matched;

## Not measured (do not guess past this)
- A real Latin letter or digit in the middle of a Japanese line: the rule predicts the same lift on that line, and the lab
  cannot say whether the line also grows to the Latin face's own height. num2's numbered boxes ("1." in the theme face on
  line 1) show no lift on line 1, so the list number does not count.
- endParaRPr with a Latin face different from the last run's: taken from the HGPGothicE box above only (both the same).
- If either matters for a deck, one small lab settles both: 3 boxes x (Latin word mid-line; endParaRPr latin differs from run).
