1. PR 2613: line scorer reads drawings with get_cdrawings, only on a page with invisible text. Identical output on 150 decks, 134 s to 66 s wall.

SLIDES_REUSE=0 turns it off. Test on 1318 decks: combined.tsv and render.tsv identical to a full score; PR side 105 s with all reused (most of it is rendering). PDFs are byte-stable (18 of 18 same binary, twice).

Exit 1 on drops. Use it instead of any hand-made A/B. dx2 still runs on starling2 (not in this script).
