# amd-opus SPEC for amd-6: where Word cuts a turned (45 degree) category name (2026-11-24)

Lab: lab/rotcap (24 charts, order.txt, Word print in word-win/), with amd-6's rotlbl2 and rotlbl3 and sa1 c11d31f3 chart 4. Lab round 1 of 2; no second round needed for the main rule.

## What sets the cap

The cap is not a length of its own. It is the HEIGHT of the turned name's box, B = (L + h) x sin 45, where L is the name's length (leading blanks counted, ellipsis counted when cut) and h is the font's line height (Calibri: 1.2207 x size). Word keeps the most whole words whose B fits.

1. Plot area left to Word (all the rotlbl labs): B <= A / 2, where A is the frame height less the bands Word takes first:
   A = H - 21.7 - legend band - title band.
   Measured: bottom legend of one 9 pt row = 22.9 pt band; 14 pt title = 26.1 pt band (the plot top moves from 11.0 to 37.1).
   With the lab's legend and no title A = H - 44.6 (window 43.6 to 45.7). This is the old "0.707 H - 42..45" rule: 0.707 x 44.6 + 13.43 = 45.0 at 11 pt.
2. Plot area set by hand, inner (sa1 c11d31f3 chart 4): the legend is NOT taken off, and the name may run down to the frame:
   B <= min( (H - 21.7) / 2 ,  H - axisY - 10.2 )   (axisY = plot bottom from the frame top; the 10.2 is a window 8.9 to 11.5).
   sa1: H 274.2, axisY 135.1, 10.5 pt bold, L 157.9 gives B 120.7; the two limits are 126.3 and 128.8, so the name is whole. Fits.
3. Plot area set by hand, outer: B <= half the outer height (one chart: 0.9 x 274, 12 words kept, 13 refused; fits).

## What does NOT matter (same word count as the control)
Chart width (300, 400, 508 pt), number of names (3, 7, 12), turn given as -45 against automatic, the plot's left edge and width, how far down the hand-set plot starts (only axisY counts).
