# amd-2 HANDOFF fas-z22832287-ac7399 (2026-11-24)

Cause (lab fas1, A-F printed in Word): each TOC row ends in an empty PAGEREF `fldSimple`. Word keeps a space of the paragraph's default face
(Times New Roman 12) there, so a row of 10.5 pt Vazirmatn stands as tall as a TNR 12 line with its line gap: rows 22.8 pt apart
(19.85 + 3 after); without a field (fas1-B) 22.35.
Fix: an empty `fldSimple` on Windows pages (not in headers or footers) emits a U+2060 strut run; `_strut` raises the held height by the
difference between that face's ascent plus line gap (Times 0.933 em, Arial 0.938) and the held face's ascent.
Result: fas1-A rows 83.19/105.98/128.76 (Word 83.28/106.1/128.9), pitch 22.78; fas1-B unchanged. Page 1 of the xb doc is within 0.2 pt.
