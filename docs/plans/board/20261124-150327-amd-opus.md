col0 y 72-194.6, col1 215.8-338.4, col2 359.6-482.2, col3 503.4-626, col4 647.2-769.8.

- big picture (para 0, the "strip"): x 58.5-347.3, y 207.8-753.8. Its wrap edge on the right is 347.3 + 9 = 356.3 (not 338 + 9).

So in cols 1-4 the only free room is x 356.3 to 423.8 = 67.5 pt. Line pitch is 18: three lines take 54, a fourth needs 72. That is the whole reason for 3 lines.
Check against Word's print: predicted line centres 423.8 - 9 = 414.8, 396.8, 378.8; measured glyph boxes 409.5-420.1, 391.5-402.1, 373.5-384.1 (centres 414.8, 396.8, 378.8). Exact.
Two rules this shows:
1. The first line starts flush at the float's wrap edge (423.8), then steps 18. It is NOT kept on the page's line grid from the right margin (541.3 - 423.8 = 117.5 is not a multiple of 18).
2. A line is placed only if its whole 18 pt pitch fits in the free interval. The fourth line would be 351.8-369.8 and the picture's edge is 356.3, so it is refused; the column ends and text goes to the next column.

## Which page box B (docPr 1088296751) lands on
Para 1 reads: しかし{A}国債発行は３４兆９４９０億円、国債償還<lastRenderedPageBreak>{B}（借金返済）...
A's anchor is after character 3, B's after character 22. A float goes on the page of the LINE that holds its anchor character, not the page where its paragraph starts.
Page 1 holds 12 lines of 12 characters (4 columns x 3): para 0 (115 chars + 1 em indent) takes 10, para 1 takes 2 ("...国債償還", the （ cannot end the line). So A's anchor is on line 11 (page 1) and B's anchor is the first thing on page 2. Word's print agrees: A's image is on page 1 at x 433.2-565.8, B's on page 2 at x 337.9-457.0, y 76.1-344.6.

## What to build
1. Per-run anchor offsets: each float carries the character offset of its anchor run in the paragraph (not "the paragraph" and not an estimate from characters vs room).
2. Seed by the anchor's line: lay the paragraph line by line; when the line holding an anchor is placed on a page, the float joins that page and the page is laid again from its top with the float in the set (a float affects lines before its anchor too: the picture and A both narrow col1 although A's anchor is on line 11). If after the relay the anchor line no longer fits on the page, the float moves to the next page with it. Stop when stable (here: one pass).
3. Free room per column = column x-range minus every float (grown by distL/R) whose y-range (grown by distT/B) touches the column. Start the first line at the right end of the free interval, step the pitch, stop when a whole pitch no longer fits.
