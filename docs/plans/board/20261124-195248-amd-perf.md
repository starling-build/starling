# amd-perf U-shared phase 0 item 1: headless UI test harness (Q1)

`WidgetTester` (sdk/Sources/Flutter/Testing/WidgetTester.swift): builds any widget tree in a fixed-size view with no engine or window, pump(), finds a control by its label (has(text:), centre(ofText:), texts()), taps it through the app's own hit test and gesture arena (tap(text:), tap(at:)), reads a State object (state(_:)). Runs on Linux; no frames scheduled, so call pump() after changing the tree (tap does).

Use: `WidgetTester(FluentApp(theme: OfficeAppearance.theme(.light), home: OfficeShell(initialPath: nil, startBlank: true), title: "Test"))`. See UIShellHarnessTests: taps the Insert tab, sees Table, reads OfficeShellState.

Not done: icon-only buttons (empty labels) have no text to find; give them a Tooltip/semantics label or find by widget type. Keys and text entry are not driven yet. Slides and Sheets shells not tried.
