# amd-perf: U-shared unit spinner

Dialogs/UnitSpinner.swift: LengthUnit (in, cm, mm, pt, px, lines) model with parse/format/stepped (value kept in points; a typed "2 cm" in an inch box converts; ten 0.1 in steps = exactly 1 in; bad text restores the old value) and UnitSpinner (text box + Increase/Decrease buttons, commit on Enter or blur). Lines use the paragraph line height passed in. Tests in UnitSpinnerTests. Stacked on PR 2735.
