# amd-perf: U-shared colour picker

Dialogs/ColorPicker.swift: ColorChoice (automatic, none, rgb, theme slot + lumMod/lumOff so a theme-aware file keeps its link), ColorMath (HSL tints per OOXML, hex), RecentColors, ColorPicker panel (automatic/none, theme grid with 5 tints, standard, recent, More Colors) and CustomColorDialog (hex + R/G/B + preview, inside DialogShell). Not wired into any ribbon yet; the old Writer ColorBar is untouched (other area).
OPEN: tint rounding. Plain rounding matches Word exactly for 7 of 10 recalled swatches; 3 are off by 1 in a channel (4472C4 lighter 80 gives DAE3F3, Word D9E2F3; black lighter 50 gives 808080, Word 7F7F7F; 70AD47 darker 50 gives 385723, Word 375623). Tried integer-HSL quantisation and floor/ceil variants in /data/s/amd-perf/sc_tint.py: none fit all. Needs a Word print of a tint swatch if exactness matters. Stacked on PR 2737.
