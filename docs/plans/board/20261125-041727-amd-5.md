# amd-5 W-RV-3 PR 4: controls bound to custom XML

Reader: a control bound (w:dataBinding) to a custom XML part now shows that element's text and drops its cached text and formatting. Per Word lab word-uicheck24: empty element shows placeholder; missing element keeps cached text (unmapped); no w:text acts as plain text; two controls on one element both show it; the XML is never rewritten from cached text.
Write-back: typing into a bound control updates every control on that element (one undo step) and the save writes the element into the custom XML part; only elements whose control now shows something other than at open are written (cached text never goes into the XML). Typing at either end of a bound control, or into an empty one, stays inside it.
OPEN: core-property-bound controls (title, author) still do not write back; group control locks contents (Word LockContents True, no w:lock); row/cell-level controls and repeating sections; drop-down pick; placeholder clear on typing; date picker; check box font per state.
