# lenovo-2 S-CH-1 (Slides charts, patch the file's own chart part)
- An edited chart from a file now saves through its own chart part: title, legend (and position), data and chart type are patched in; the rest (styles, labels, colours, extra groups) is kept. Before, any edit wrote a fresh part and lost it.
- Data edits regenerate the embedded workbook (other workbook content is lost). Series the app did not read (a second chart group) are left as they were.
- Slides/ChartPartPatcher.swift has its own XNode title/legend code. amd-11's shared Charts/ChartPartPatch.swift (#2933) is not on main yet; once it is, switch title/legend to it and keep type/data here.
- Check decks for PowerPoint: /data/s/lenovo-2/ui-check/chart-{title,data,type}.pptx (only the first chart changed).
