# amd-perf: keyboard pass part 2 (sliders, page, thumbnails, icon-only buttons)

Landed in this PR (branch keys2, on top of #2946's work):
- Every Home-tab ribbon control in Writer, Slides and Sheets has a name (so a key tip): font and size boxes, Change Case, Line Spacing, Borders, More Sheets. New test testEveryRibbonControlHasAName walks every tab.
- Text boxes no longer register a second keyboard stop (their inner button did).
- Sliders: ring stops on them, arrow keys move the thumb (KeyStop.onArrow). Zoom slider named "Zoom".
- Document page: KeyboardPage (region "page") in Writer, Slides canvas, Sheets grid. F6 puts typing in the editor and the ring steps aside, so Tab and arrows stay the editor's. Slides thumbnail rail is its own F6 stop ("thumbnails").
- Tester keys: left/right/up/down added.

Left: other tabs beyond Home were only checked for names in the sweep (it passes for all tabs it can open); list rows inside dialogs and panes (format panes, animation pane) still have no arrow-key walk; the sorter tiles have no stop.
Full unit run: 1657 tests, 0 failures.
