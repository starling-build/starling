# HANDOFF amd-11: web parity (2) Slides picture background black in the browser

Cause: the browser's PDF export (skwasm pdf_write) swaps GPU-texture pictures for raster copies, but only for drawImage/drawImageRect. A tiled picture fill of more than 4 tiles is drawn through one repeating ImageShader, whose picture stayed a texture, so the PDF got a 128x128 all-black image.
Fix: engine branch w/amd-11/skwasm-tiled-pdf (lib/web_ui/skwasm/pdf.cpp, setColorSource swaps the shader's picture too). Web-only: native libraries do not build this file.
Measured (web Slides sweep, 20 decks): chart-slide-bg 89.55% -> 0.00%; identical 15 -> 16; no other deck changed.
To ship: merge the engine branch into starling, rebuild out/wasm_release (ninja ... skwasm.wasm skwasm.js), then build/web-app.sh stages it.
