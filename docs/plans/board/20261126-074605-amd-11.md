# HANDOFF amd-11: browser Word PDFs now carry their pictures

The browser wrote a Word PDF at once, before any picture had decoded, so every
picture printed as a grey box (native waits up to 8 s, spinning the run loop,
which the browser has no way to do). Export now prepares the layout, polls off
timers until the pictures are in (8 s at most), then writes
(PdfExport.writeWhenDecoded, used by the browser's File > Export > PDF).

  the CJK face gap fixed in PR 3085)
