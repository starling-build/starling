# HANDOFF amd-perf: browser screen readers, part 2 (ribbon tabs, shortcuts, text boxes, Sheets and Slides names)

Stacked on #3159 (part 1, with the merger): this PR carries that commit too.
wideab (base origin/main c072a95b3, same build mode): every set (756 lo xa xb xd xs sa1 sa2 dx2) up 0 down 0, no movers. Full units 2266, 0 failures; node a11y-test 7 pass. Engine c4d419b658 (patches applied=29 failed=0).

Done:
- Ribbon tabs are tabs for a screen reader: role tab plus selected state (the open tab is "selected"); a reader's tap opens the tab. File is a button. Before, both read as plain text.
  The framework's Semantics widget gains `role:` (SemanticsRole), carried through SemanticsInfo into the snapshot node (`role`). The web layer sends it as flag 4096; a11y.js gives role=tab with aria-selected.
- Ctrl/Cmd+B, I, U announce "Bold on/off" etc. in Writer/Slides text (RichEditable) and on Sheets cells (SheetGrid). Button clicks already announced, so the announcement sits at the key handlers only (no double speech).
- Text boxes are read once: the drawn value/placeholder text inside FluentTextBox is excluded from semantics (the field node already speaks it). A custom placeholder widget stays readable. This also fixes "Find in document" appearing twice (part 1 gap).
- FluentTextBox gains `semanticLabel:`; the Sheets name box reads "Name Box" (value A1) and the formula bar "Formula Bar". Before, both were unnamed text fields.
- A named ComboBox reads as its name with the shown choice as value, when the choice is plain Text; a11y.js joins a named control's value into its aria-label ("Font, Calibri", "Font Size, 11"), since a reader speaks only the name of a button (text fields keep the value as content). Before, the name went only to keyboard stops and a reader heard the bare "Calibri"/"11".
- Slide thumbnails read "Slide N" with selected state and a tap, not the bare number.
Tests (each fails before, passes after): SemanticsWidgetTests.testRibbonTabsAreTabsWithTheOpenOneSelected, .testTextBoxTextIsReadOnceAsTheFieldNotAgainAsPlainText, .testAComboBoxIsReadByItsNameWithTheChoiceAsItsValue; ScreenReaderTests.testTheBoldShortcutSaysOnThenOffInWriterAndSheets, .testTheSheetsNameBoxAndFormulaBarHaveNames, .testASlideThumbnailIsReadAsSlideOneNotABareNumber; test/web/a11y-test.mjs (tab case, spoken name).
Checked in Chrome (?a11y=1, web-drive, docs textedit.docx, lo-3columns.pptx, chart-tdf111173.xlsx): tabs, File, Bold on/off, Name Box, Formula Bar, "Font, Calibri", "Font Size, 11", Slide 1, no duplicate text-box text.
