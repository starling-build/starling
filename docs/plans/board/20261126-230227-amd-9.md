# HANDOFF amd-9: legacy .ppt reader, fonts, theme and text-box styles (pushed, NO PR: speed control)

Branch amd9-ppt2 (on top of PR #3148, the metroBlob frames). Not opened as a PR because of the
2026-11-26 speed control; open it with pr.sh when the coordinator allows.

What it does:
- Reads the Environment record (0x03F2; the old code looked for 0x03FF, so the deck's font list was never read):
  the fonts, the default character props (TextCFExceptionAtom) and the document's own text styles,
  written as presentation defaultTextStyle.
- Keeps the master's round-trip theme (RoundTripTheme12Atom 0x040E) with the deck's own colours in its 8 slots.
- A style level that names no font keeps the level above's font (then the document default).
- A non-placeholder text box with body/title text gets its master's style for that text type as lstStyle,
  with the shape's own TextRuler margins (PowerPoint's conversion does the same).
- An empty paragraph keeps the size of its paragraph mark (endParaRPr): the biggest single gain.
- An IMsoArray size with or without its 6-byte header keeps the next complex property in place.
