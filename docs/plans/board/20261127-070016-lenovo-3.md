# HANDOFF lenovo-3: Sheets chart value-axis step follows the label face (lab xl-step2)

**Landed (this PR):** on a sheet's 2-D value axis the automatic step now comes from the label face's print row,
not a fixed 13 pt pitch.
- Plot inside height P = H - max(22, lineEm x size + 10) (H = chart frame height, pt).
- Most intervals = floor(P / s) - 2, clamped to 1..10, with s = 0.917 x row(face, size) x 72/600
  (`SheetPrintMetrics.textRowDots`). Code: `ChartPainter.sheetValueSteps`.
- Fits all 120 charts of lab xl-step2 (8 faces, H 60..200, Excel COM MajorUnit and the print agree) and every step
  of lab xl-step (129 charts). The 0.917 is pinned to about 0.9169..0.9171 by the lab; it was not tuned on the corpus.
- Tests: SheetChartStepTests (the transitions from lab xl-step2's com.tsv).
