# HANDOFF amd-1: turned-cell ideographs (tbRl turns them, tbRlV centres them)

What landed in this PR:
1. Plain tbRl turns ideographs with the Latin (a quarter turn). Only tbRlV and
   tbLrV stand them upright. Lab turnpad3 (Word's print of 职业资格 in SimSun,
   tbRl beside tbRlV, mode 15). Test: TurnedCellUprightTests.

   for every face Word for Windows draws (it was only the Japanese faces). Before,
   they sat about 0.9 pt off Word: the box middle is about 0.076 em from the
   face's line middle.
