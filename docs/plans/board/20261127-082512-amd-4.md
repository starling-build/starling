# HANDOFF amd-4: fraction box and math drawing offset (lab fraclab, follows #3179)

Lab fraclab (/data/s/amd-4/lab/fraclab, Word print in word-win/), single-spaced cases measured by ink against Word's print.

Fixed:
- Inline fraction (Windows pages) uses Cambria Math's own constants: rule 133/2048 em thick; numerator up max(1200/2048 em, axis + half rule + 260/2048 em + numerator depth); denominator down max(1030/2048 em, denominator height + 1.5 rules - axis). - Drawing offset: math text was drawn about 0.75 pt off its layout because the engine rounds a line to whole points. Math text is now laid out at 16x with fractional line heights and painted scaled down, so it stands on the face's own baseline.
- U+00D7 added to the Cambria Math ink table.
- Result: every single-spaced case's next line is within 0.15 pt of Word (B 55.23 vs 55.08, A 57.52 vs 57.38); the nested-sum case's "1-" is exact.
