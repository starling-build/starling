# HANDOFF lenovo-3: sheet date axis counted in months (chart-tdf134118, lo-tdf165503)

Landed in this PR:
- A `c:dateAx` with baseTimeUnit months and no majorTimeUnit now has one slot per month from the first date to the last;
  each point stands in its own date's month. A row with no date gets no slot. Before this we made one slot per row
  (chart-tdf134118: 14 slots for 4 dates; Excel has 4 slots, May to Aug, named on the 1st).
- A line runs on over months that no row falls in; a row whose value is blank is still a gap (lo-tdf165503: Apr 2021 to
  Dec 2021 to Oct 2022 as one line, as Excel prints it).
- A value whose date is blank still counts on the value axis (lo-tdf165503's 15: Excel's axis runs to 16).
- Only when no two dates share a month (those would share one slot; not modelled).

Measured (page pixel diff against Excel's print, base = main tip):
- chart-tdf134118: labels now at Excel's x (283.8 vs 283.7, pitch 96), plot bottom within 1 pt (was 5.3 high). Pixel diff 0.228 to 0.234.
- lo-tdf165503: slots and line now match Excel; pixel diff 0.406 to 0.461 because the 22 labels are drawn at 45 deg where Excel stands them upright.
- The other 4 books with such an axis (en-5c02fc7840, en-fb84c02790, es-d879fc1952, es-ffd552d4d4) are unchanged.
