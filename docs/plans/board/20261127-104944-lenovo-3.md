# HANDOFF lenovo-3: sheet bubble chart axes

Landed in this PR (sheet bubble charts only, guarded by onSheet):
- Both axes reach a sixth of the data's spread past each end (times the bubble scale; lab xl-bub2), with no 5% headroom. A single value pads by a fifth of itself (x = 1 alone stands 0 to 1.2).
- The x axis takes its step from the unpadded data, then extends to the next tick past the pad. This can go beyond the scatter x axis's 10-step / 36.4 pt rule (x = -3..4 stands -5..6 by 1, 11 steps).
- Series with no y values keep their points (x = 1..n from the sizes or x list). The frame, axes and gridlines are drawn with no discs. A chart with no y values at all gets y -0.2 to 1.4.
- The live sheet reader now reads values of bubble series without sizes (the axes use them; discs are still not drawn).

Evidence: lab bubble1 (amd-1, 22 Excel prints). Every axis label now matches Excel; before, 17 differed.
- chart-invertIfNeg_bubble drew nothing; now it matches Excel.
- chart-bubble_chart_simple is unchanged and still matches Excel.
- These are the only two bubble books in the corpus.

Left open:
1. Bubble size data labels. Excel prints them when `c:dLbls` has no `showBubbleSize` element (lab control, zy, zy-neg, control-neg); we print none. This belongs to the data-labels queue.
2. A scatter/bubble y axis crosses at x = 0 when x runs negative. In lab x-neg, Excel puts the y axis at x = 0; we put it at the left edge. Separately, when there are no y values Excel puts the x labels at the plot bottom.
3. Lab xl-bub2 (lenovo-3/axl/lab/xl-bub2, 8 charts) is waiting on prints. It tests a constant y and a top that lands exactly on a gridline. It may refine the -0.2..1.4 constant into a general rule.
