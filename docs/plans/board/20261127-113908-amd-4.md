# HANDOFF amd-4: W-PA-6 section breaks (finishes W-PA-6)

Landed in this PR (stacked on #3209, the column break):
- Layout > Breaks menu: Section Next Page, Continuous, Even Page, Odd Page.
- The text before the caret becomes a section that keeps the caret's section's page, headers and start; the rest starts as chosen. One undo step.
- A break made in the last section is saved as a full copy of the last section's sectPr, with the same header/footer references. Without them Word gives that new first section no header at all.
- The paragraph after a page-starting break gets pageBreakBefore, not written to the file, the same as the reader marks a file's section break. The layout needs it: without it, Next Page did not start a page.
- Tests: BreaksTests (undo step, page each kind starts on: Next 2, Continuous 1, Odd 3, Even 2, saved XML with header refs on both sections and read-back, break inside an earlier section rewrites only its w:type).

Left: no Word lab print of a saved file (the XML is Word's own form). Deleting a section break by joining paragraphs is not special-cased.
