# HANDOFF amd-5: Word refused saves of documents whose theme has its own rels (dx2-16de187a)

- open300 Word check: dx2-16de187abbb5aca878248ece205da13d7e850ca8 refused as corrupt.
- Bisect (original plus one of our parts): [Content_Types].xml, document.xml.rels and document.xml each refused.
- Cause: since #3190 a save keeps the theme's own rels (word/theme/_rels/theme1.xml.rels, the theme's picture).
  The kept-parts loop runs in name order and "_rels" sorts before "theme1.xml", so the rels file was taken for
  the theme: the document linked it as its theme and the content types typed it as a theme.
- Fix: a kept .rels part is never a theme (it takes the package's rels type). Our resave links theme/theme1.xml.
- Test: DocxPreservationTests.testAKeptThemesRelsAreNotTakenForTheTheme (fails without the fix).
