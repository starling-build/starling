# X-DA-3c Edit Rule (lenovo-3) — HANDOFF

Branch w/lenovo-3/cf-edit. PR waits for pacing.

What it does:
- Manage Rules has an "Edit Rule…" button. It opens the Conditional Formatting form, filled in from the rule, with an "Applies to" box and "Keep current format" as the first look.
- OK is one undo step (`editConditionalRule`). The rule keeps its rank and Stop If True. If the range is unchanged it is rewritten in place; otherwise it moves to its new range (or to the 2010 ext block for 3 stars / 3 triangles / 5 boxes).
- No silent loss: `conditionalRuleForEdit` rebuilds the rule from the form and compares it to the file's XML. Anything the form can't hold (theme colours, custom cfvo, a reversed icon set, ...) is refused with a message and left as it is. Colour scale colours, data bar colour and "or equal to average" carry over from the original rule.
- A look with borders or a number format can only be kept.
- The form gains two kinds: Errors and Dates occurring.
