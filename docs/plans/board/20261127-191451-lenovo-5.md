# lenovo-5: W-OB-3 paint order across paragraphs (LANDED in this PR, follows the 180849 design)

What changed: with Word rules on, a floating object in front of the text (not behindDoc, VML z-index >= 0) is no
longer painted inside its own paragraph. It is recorded with its piece frame (clip, offset, column shift) during
the text passes and painted after all of them, sorted by page, then relativeHeight (or VML z-index), then
document order. So Bring to Front on a picture in paragraph 1 now draws it over a picture in paragraph 5.
Hit-testing (click picks the top object) uses the same order; behind-text objects rank below all front ones.

Test: PictureWrapTests.testFloatsPaintInStackOrderAcrossParagraphs (red/blue swap with Bring to Front).
