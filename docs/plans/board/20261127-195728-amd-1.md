HANDOFF amd-1 W-TB-1 (part): table move handle

Landed in this PR:
- Hovering a table shows Word's move handle: a small box with a four-way arrow just outside the table's top-left corner. The cursor becomes the move cursor over it.
- Clicking the handle selects the whole table (every cell, one block), as in Word.
- The controller has a command that selects a named table wherever the caret is.
- Tests: TableMoveHandleTests (select by name; a click on the handle selects the table, a click beside it does not).
