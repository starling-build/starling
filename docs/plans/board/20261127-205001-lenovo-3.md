X-PR-1 and X-SH-1 were mostly on main already (#2752 Page Setup dialog, print area/titles, breaks; #2796 print choices;
ac424e70e, ba6d225ee, 25bda3ab8, 748e27d98 tab drag, Ctrl+drag copy, Move or Copy, Tab Color, Select All Sheets).

This PR adds what Excel's Page Layout tab had and ours lacked, each one undo step through setPageSetup / setPrintArea:
- Page Setup group: Margins (Normal 0.75/0.7/0.3, Wide 1/1/0.5, Narrow 0.75/0.25/0.3, Custom Margins), Size (paper list
  with a tick, More Paper Sizes), Print Area (Set from the selection, Clear when one is set), Print Titles (opens the dialog).
- Scale to Fit: Width and Height (Automatic, 1-9 pages, More Pages); both Automatic turns fitToPage off; Scale spinner only
  while both are Automatic (Excel greys it).
- Sheet Options: Gridlines and Headings, View and Print.

Excel open check: lab/xpr1c/page-layout.xlsx (wide margins, landscape A4, area A1:J50, title row 1, fit 1 wide, gridlines
and headings printed) and page-scale.xlsx (fit 0 x 2 then back to scale 75) sent to starling-bd.
Driver: lab/xpr1c/xpr1c.script with OFFICE_FILE=lab/xpr1c/driver-start.xlsx (grid cell coordinates are estimates).
