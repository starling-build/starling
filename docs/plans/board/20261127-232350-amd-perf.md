# amd-perf: U-shared dead-button census (Writer, Slides, Sheets): list, and the PR that wires or hides them

Census by reading every ribbon tab, menu, context menu, File tab, status bar and dialog of the three apps (2026-11-27,
main e9720d35b). The ribbon's icon buttons were already swept by ControlSweepTests (taps each, all live); the dead
ones were in menus, in Writer's shared groups that Slides and Sheets reuse, and in notes.

Cause of most: Slides and Sheets each have their own OfficeSession, and the Writer groups they reuse (Clipboard,
Paragraph, Table Layout, Review, File > Info) call hooks only Writer's shell sets. In Slides those items did nothing.

## Slides (17 dead)
- WIRED: Home > Editing > Select All (with no text being edited it selected nothing; now picks every shape on the
  slide, as Ctrl+A does). Table Layout > Select > Draw Table / Eraser (now the deck's table pen, as Table Design >
  Draw Borders). Review > Word Count (counted only the text box being edited; now every slide's text).
- HIDDEN (no Slides command yet): Paste Options chevron (Keep Source, Merge, Picture, Keep Text Only, Paste
  Special); Line Spacing > Paragraph Options…; Borders > Borders and Shading…; Bullets/Numbering > Define New
  Bullet…, Define New Number Format…, Set Numbering Value…; Table Layout > Table Properties…, Formula…, Sort…,
  Convert Table to Text…, Split Cell…; File > Info > Properties….
- Left as is: Transitions > Effect Options "No options" (greyed note for None and Fade, which have no options);
  Animations: the note shown for animations this app does not edit.
## Sheets (1 dead)
- HIDDEN: File > Info > Properties… (no workbook properties model). Everything else is wired through SheetsShell._command.
- Left as is: Name Box "No names defined" (a placeholder row, as Excel).
## Writer (no fully dead button; fixes)
- REMOVED: Review > "Coming later" note (it said footnotes, a table of contents, shapes and text boxes are not in
  this build; they are; track changes and comments have no commands and are simply not shown).
- WIRED: Shape Format > Group with one shape picked (was greyed for good): turns on Select Multiple and says to tap the others.
- FIXED: Home > Borders > All Borders left out the line between paragraphs (same as Outside Borders).
- Left (not dead, noted for owners): Insert > Header and Footer both focus the header line (W-page); Borders and
  Shading paragraph shading saves a theme colour as a fixed colour (W-text); Print ignores the output argument and
  Find ignores scope (neither offered in Writer).

## The rule now in code
A shared item shows only when its app's shell sets the hook (Ribbon._pasteOptions, _tableTools, the dialog items,
Backstage Properties). A Slides or Sheets owner who wires a hook gets the item back with no ribbon edit.

- Test: DeadControlTests (9): no tab shows a "not in this build" note; Slides menus lack the Writer-only items
  that Writer shows; Properties only in Writer; Slides Select All, table pen, deck word count; Writer All Borders.
- Driver script (mac-ipad, 1440x932, blank deck): /data/s/amd-perf/scratch/deadbuttons/slides-dead.script
- Screen-reader labels: nothing unlabelled met in this pass (AccessibleNameSweepTests covers ribbon buttons, dialog
  fields and titles). Not covered by any sweep: context-menu and File-tab items; next pass.
