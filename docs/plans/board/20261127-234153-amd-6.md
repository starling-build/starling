# HANDOFF amd-6: Slides Shape Format tab (coordinator request after the stx1.pptx Mac run)

Found: Slides had no Shape Format tab at all, for placeholders, text boxes or drawn shapes (only Picture
Format, Table Design and Chart Design existed).

Done (this PR):
- Shape Format now shows in the tab strip while a drawn shape, placeholder or text box is selected, as in
  PowerPoint (which shows it but does not switch to it). Pictures keep Picture Format. Deselecting returns
  the ribbon to Home if Shape Format was open.
- Groups: Insert Shapes; Shape Styles (Fill, Outline, Effects); Accessibility (Alt Text); Arrange (Bring
  Forward, Send Backward, Align menu with distribute and Align to Slide, Rotate menu); Size (Height and
  Width boxes, Format Shape…). Each command is the Home Drawing group's own, one undo step.
- Tests: SlideShapeFormatTests (3: which selections show it, placeholder shows it and deselect goes Home,
  Height box and Send Backward undo and save).
- Mac script: /data/s/amd-6/scratch/shfmt/shfmt.script with
  OFFICE_FILE=/data/s/amd-6/scratch/shfmt/shape-format.pptx.

Left: WordArt Styles and the Shape Styles gallery (S-SH-4, S-WA-1). Picture Format is unchanged.
