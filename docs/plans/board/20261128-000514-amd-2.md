# HANDOFF amd-2: underline styles drawn as their kind (Word text)

Completes W-CH-2's Font dialog: a dotted, dashed, wavy, double or heavy underline now draws as that kind, in its own colour (w:u w:color), instead of a plain line in the text colour.

- Map: double -> double; dotted/dottedHeavy -> dotted; dash/dashLong/dotDash/dotDotDash (+Heavy) -> dashed; wave/wavyHeavy/wavyDouble -> wavy; thick and *Heavy at twice the weight.
- Test: UnderlineStyleTests. Lab: /data/s/amd-2/scratch/ulpaint/ulkinds.docx (13 kinds, red rule under blue text, double + strike).

OPEN (not done here):
- "words" still draws under spaces; dot-dash kinds draw as plain dashes; wavyDouble draws one wave.
- A run that is underlined AND struck (or tracked) keeps the plain line: the engine has one decoration style per run.
- Slides draws its own rules (_paintRules) and still ignores the kind.
