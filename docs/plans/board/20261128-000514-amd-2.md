# HANDOFF amd-2: underline kinds drawn as Word draws them (Word text, Slides)

W-CH-2 follow-up: a styled or coloured underline (w:u w:val / w:color) is drawn by our own painter at Word's sizes; the plain
single underline stays the engine's, so most documents render byte for byte as before.

- Sizes measured on Word's print of the lab (Aptos 12 pt), in u = size/50: single at the face's underline position, 1u thick;
  double 0.5u lines at top-u and top+3.5u; thick and *Heavy 4.5u from top-u; dotted 6u on 6u off; dash 16.5/8; dashLong 33/16.5;
  dotDash 12.5,4,4,4; dotDotDash 9 then 3 x5; wave amplitude u, half wave 5u, stroke u (wavyHeavy 4u); wavyDouble two 0.4u waves.
- "words" leaves spaces and tabs bare; trailing spaces at a line end get no rule (Word mode).
- A struck run keeps its underline kind (the engine draws only the strike there).
- Slides: a:rPr u (dbl, heavy, wavy, dotDash...) maps to Word's names and draws the same way; plain sng is unchanged.
- Writer: Normal keeps its own alignment, indents, tabs, underline and next style on save (they were dropped; a changed
  Normal from a file lost its pPr and rPr). Normal's spacing stays only in the document defaults.
- Tests: UnderlineStyleTests (sizes via a spy canvas, struck kind, Slides names, colour, Normal save round trip).
- Lab: /data/s/amd-2/scratch/ulpaint/ulkinds.docx, Word's print in word-win/.
