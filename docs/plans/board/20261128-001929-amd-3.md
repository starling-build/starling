# amd-3: X-FM-3 Borders pen (Line Color, Line Style)

Home > Borders now has Line Color (Automatic, the palette, More Colors…) and
Line Style (Thin … Hair, the chosen one checked) before More Borders….
They set the pen the presets draw with, as in Excel: every preset takes the
pen's colour; a plain preset takes the pen's style, while a preset with its
own weight (Thick, Double) keeps that weight. The pen is per session, not saved.

Also fixed in the shared menu: picking an item in a submenu now closes the
whole menu (it left the parent open; Slides' Glow/Shadow submenus had the same bug).

Tests: SheetsBorderPenTests (model and the menu path).
Driver: /data/s/amd-3/scripts/xfm-borderpen.script with OFFICE_FILE=/data/s/amd-3/scripts/xfm.xlsx.

X-FM-3 left: Draw Border / Draw Border Grid / Erase Border modes, double
underline, superscript/subscript, pattern fill.
