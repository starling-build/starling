# S-AR-1 multi-selection handles (amd-6)

What: with several shapes selected (Cmd+A, Shift+click, marquee) every selected shape now shows its eight sizing handles
(two for a line), as PowerPoint does. Before, only the 1.25 pt outline was drawn, and on shapes whose own border is the
accent blue it was invisible, so the Mac run read "no outline or handles".
Handles in a multi-selection are marks only: a press on one moves the selection. PowerPoint resizes all selected shapes
from such a handle; that is still OPEN (S-AR-1 remainder), as is the Selection Pane.
Test: SlideMultiSelectTests. Driver: /data/s/amd-6/scratch/sar1/sar1.script with distribute.pptx beside it.
