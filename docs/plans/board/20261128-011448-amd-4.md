# HANDOFF amd-4: W-FD-1 done (fields)

What this PR does:
- F9 was broken: two F9 handlers collided, so the first (date and properties only, whole document) swallowed every F9,
  Shift+F9 and Alt+F9. Now one F9 updates the fields in the selection or at the caret, every kind: PAGE, NUMPAGES,
  REF/PAGEREF, table formulas, DATE/TIME, document properties, FILENAME. Shift+F9 / Alt+F9 show codes again.
- Insert > Text > Quick Parts: Field... dialog (11 field names with Word's descriptions, date/time formats, Preserve
  formatting = \* MERGEFORMAT) and Update Fields (every field when nothing is selected). The old Field menu inserted
  nothing (empty results are refused).
- Ctrl+Shift+F9 unlinks the fields in the selection or at the caret (one undo step).
- Field codes show as "{ PAGE }" (instruction trimmed), as Word does.
- office-ui-gaps.md: W-page rows marked with what landed (W-PA-6, W-PG-1, W-PG-2, W-HF-1, W-HF-2, W-FN-1, W-FD-1, W-FD-2).

Left: field switches beyond \@ (\* roman on PAGE is ignored), the rest of Word's field list.
