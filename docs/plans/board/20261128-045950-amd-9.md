# HANDOFF amd-9: S-ED-1 finish (slides on the clipboard, Use Destination Theme)

Landed in this PR:
- Copy Slides puts the slides on the system clipboard: titles as text, a token, and the slides as a pptx of their own
  (application/x-starling-slides-slides / -deck, registered with the other private types; Cocoa and Win32 carry
  every registered type, GTK still text only).
- Paste in the pane or sorter: this deck's own copy from memory; another window's or process's from the pptx.
  Use Destination Theme (default) restyles to this deck's theme and drops the source master's shapes; Keep Source
  Formatting spells the source background out on each slide and stops its colours following a theme. Paste Options
  button under the last pasted thumbnail (H / K), one undo step.
- Shapes: Use Destination Theme is the default way too (another deck's shapes restyled to this theme).
- #3317 Mac fixes: a picture / Keep Text Only of copied shapes lands where the shapes copy was (picture at the shapes'
  size); pasted text and Insert Text Box take the deck's text-box defaults (presentation defaultTextStyle lvl1, then
  master otherStyle; DeckTheme.textBox*), theme body font 18 pt when the file says nothing. pasteopt.pptx's own minor
  font IS Times New Roman; its text-box default is Arial 24 yellow centred, which is what PowerPoint draws.
- Tests: SlidePasteDeckTests (4). Full units 2701, 0 failures.
- Mac scripts: lab/slidepaste/1-copy.script then 2-paste.script (two processes), in /data/s/amd-9/lab/slidepaste.
