# HANDOFF lenovo-5: W-OB-5 charts, PR 1 (Chart Design on a Word chart)

- A selected chart in a Word document shows Chart Design: Change Chart Type, Edit Data, Chart Title, Legend,
  Data Labels, Axis Titles, Grouping. Each edit patches only what changed in the chart part (ChartPartPatcher,
  shared with Slides) and writes changed cells into the embedded workbook; part and workbook change as one undo step.

- Multi-level category axes (c:multiLvlStrRef) keep all levels on a data edit; the edit goes to the inner column.
