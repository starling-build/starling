# HANDOFF amd-6: S-SH-1 follow-up, drawn Smiley Face had no mouth

- Cause: a shape drawn in the app has no evaluated preset path (only file shapes get one from the reader), so the painter used the preset's combined fill outline, which leaves out stroke-only contours (smiley mouth). The gallery icon draws contour by contour, so it showed the mouth.
- Fix: SlidePainter paints a drawn preset contour by contour, evaluated at the shape's current frame with its adjust values (lines and elbow connectors unchanged). Writer untouched.
- Test: SlideDrawnPresetContourTests (fails without the fix: 1 stroke, no mouth). Units -j 8: 2737 run, 0 failures.
- Still open (for others): file shapes keep the path evaluated at load size, so a resized file roundRect stretches its corners; accentCallout1-3 / accentBorderCallout1-3 draw nothing (FreeformGeometry.parse drops a path that continues after close without a moveTo).
