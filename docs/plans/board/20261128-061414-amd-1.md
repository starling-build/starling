# HANDOFF amd-1: W-TB-5 part 2, nested tables edited in place

- Insert > Table with the caret in a cell nests the new table in that cell (one undo step; width = the cell less its margins).
  It is a block in the outer cell: a click selects it, a second click types in its cells (the text-box editor), Escape writes
  it back as the nested w:tbl (one undo step). A nested table read from a file edits the same way.
- Word lab tb5n (lab/tb5n in amd-1's tb4f checkout, not in git): all 3 files open clean in Word, one nested table at level 2, text as typed.
  Word places the inner columns at x 83.3 / 157.5 / 231.7 pt (74.2 pt apart; ours writes 74.4), inner row 2 at y 125.1, outer row 2 at y 193.1.
- OPEN: a nested table that floats (w:tblpPr) or holds fields, revisions, content controls, pictures, or a third level stays as read, not editable.
- OPEN (UI): it takes two clicks to type in a nested cell; Word takes one. Typing goes through the box editor, not inline in the page.
- Mac script: lab/tb5n/tb5n.script (OFFICE_FILE=tb5n-1-inserted.docx).
