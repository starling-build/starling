# HANDOFF amd-6: S-SH-1 follow-up, a resized file preset stretched its corners

- Cause: a preset shape read from a file keeps the outline evaluated at load size; resizing scaled that old path, so a rounded rectangle's corners (and an arrow's head, any adjust-sized part) stretched. Its text rectangle share stayed at the load size too.
- Fix: when a shape's frame changes size, its own preset outline is evaluated again at the new size with its adjust values, and the text keeps to the preset's text rectangle (shared with the yellow-handle path). Lines, elbow connectors and placeholders whose preset comes from the layout are left alone (the layout's adjust values are not kept on the shape).
- Test: SlideDrawnPresetContourTests.testAFileShapeResizedKeepsItsCornersAndAdjusts (roundRect and rightArrow with own adjusts, resized, then undo). Fails without the fix.
