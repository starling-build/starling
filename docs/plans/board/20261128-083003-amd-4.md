# HANDOFF amd-4: W-PG-1 leftovers (2 pages per sheet, book fold)

Landed in this PR: Page Setup > Margins > Multiple pages offers Normal, Mirror margins,
2 pages per sheet, Book fold (sheets per booklet), Reverse book fold. Each saves its Word
setting in schema order and reads back. A sheet orientation stated across the page shape
(w:orient="portrait" on a wide page) is now kept on save.

2 pages per sheet layout (from Word prints, lab pg1c, T72 B36 L90 R54 gutter 18; ours within 0.3 pt, 8 vs 8 pages on all 5 files):
- The page is the stored size; the pair runs along the stored w:orient (the sheet), not the page shape.
- Landscape sheet: page 1 left = R+g, right = L; page 2 left = L, right = R+g.
- Portrait sheet: left/right = L/R, no gutter; page 1 top = B+g, bottom = T; page 2 top = T, bottom = B+g.
- gutterAtTop (landscape sheet): every top = T+g, no vertical swap; page 1 left = R+g, right = L-g; page 2 = L/R.
- Mirror margins changes nothing. Untested: portrait sheet with gutterAtTop.

NOTE, Word export limit: Word cannot export a book-fold document to PDF when its left and
right margins differ (labs pg1d-pg1f: 90/54 and 54/90 both fail; top/bottom, header/footer
and page size do not matter; Word's own c7d0f78 with equal sides exports, 28 pages). Our XML
matches what Word writes. Not chased (starling-bd). So book-fold layout is unchanged: there is
no Word print of the common case to match.
