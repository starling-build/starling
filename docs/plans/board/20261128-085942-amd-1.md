# HANDOFF amd-1: W-TB-5 nested tables, follow-up to #3382

Landed in this PR (fixes asked for after the Mac run of #3382):
- A nested table that holds fields, tracked changes or pictures is editable (was read-only). Revision ids written
  from the edited table are shifted above every id used elsewhere in the file, so they stay unique.
- While the caret is in a nested table the editor lays it out exactly as the page does (same width and rules),
  so the table no longer draws ~6 px narrower while edited.
- The status bar word and character counts inside a nested table are the whole document's, as Word shows.
- Gesture that picks a nested table as an object: Left (or Up) arrow from the start of the line under it.
  Shows the Table tabs, no Shape Format.
- Test: NestedTableShellTests checks layout width while editing, the document word count, the Table tabs after
  Escape, and the Left-arrow pick. NestedTableTests checks field/revision and picture cells round-trip.

Lab: lab/tb5d (tb5d-1-source.docx, tb5d-2-edited.docx for Word; tb5d.script for the Mac, runs on tb5c's file).
