# HANDOFF amd-2: W-ED-3 Insert Symbol (and Ctrl+G per platform for W-ED-2)

Landed in this PR:
- Insert > Symbol gallery: Word's 20 defaults, recently used first (shared "recent-symbols" setting with the dialog).
- More Symbols: font list, 26 subsets that follow the selected character, Character code in Unicode (hex) or ASCII (decimal), status line; Special Characters tab with Word's 20 rows and shortcuts. One dialog size on both tabs (no overflow; the old Font/Subset row overflowed).
- Typing after a symbol inserted in a symbol font goes back to the font in use before it (Word). Before, text after a Wingdings J stayed Wingdings.
- Nonbreaking and optional hyphen save as w:noBreakHyphen / w:softHyphen (test).
- Ctrl+G is Go To on Windows and Linux; Cmd+G stays Find Next on the Mac (test per platform). Find and Replace keeps one size on all tabs and with Special open.
