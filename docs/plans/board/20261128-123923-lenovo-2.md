# HANDOFF S-PI-1j (lenovo-2): Picture Border, Picture Effects, Corrections previews

New in Picture Format:
- Picture Styles group: Picture Border (colour, weight, dashes; no arrowheads) and Picture
  Effects (shadow, glow, reflection, soft edges). Bevel and 3-D Rotation are NOT offered for pictures: a
  picture's sp3d is not written yet (a kept picture's own sp3d/scene3d is left untouched).
- Saved as a:ln and a:effectLst in the picture's spPr, in schema order (geometry, ln,
  effectLst). A kept picture is patched in place (its other effects stay); a new picture is
  written with them. Glow on a picture is now read too. Test:
  SlideIdentityTests.testPictureBorderAndEffectsSaveOnKeptAndNewPictures.
- Corrections (starling-bd's ask after #3423): the 25 text rows are now a 5x5 grid of the
  selected picture drawn with each Brightness/Contrast pair (brightness across, contrast
  down), the pair in its tooltip, the current one outlined. Test:
  UIShellHarnessTests.testSlidesCorrectionsGridPreviewsThePictureAndPicksOnePair.
- Checked by render: glow + border draw around the one picture only.
