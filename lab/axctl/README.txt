ActiveX (MS Forms) control lab, generated by axgen.py (amd-6). 40 decks, 4 controls each, one control type per deck.
Print each to PDF with PowerPoint for Windows (File > Export/Print to PDF, no changes), named <deck>.pdf, same folder.
Each control's name tells its variant: <type>-<enabled|dis>-<L|C|R>-b<border 0|1>, back-green-opaque/clear, font-times-10, text-red,
for commandbutton/label/scrollbar/spinbutton see their name. Textbox/listbox/combobox/checkbox/optionbutton/togglebutton: 14 variants each.
