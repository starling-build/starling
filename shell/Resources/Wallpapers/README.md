# Wallpapers

- `city-sunset.png` — default wallpaper: the same voxel-inspired San Francisco
  composition relit for early evening, matching the sunset 3D world.
  Edited with the built-in image-generation tool; see [prompt](city-sunset.prompt.md).
- `city-night.png` — alternate wallpaper: a dark, voxel-inspired San Francisco
  waterfront with warm window lights, a cable car, ferry and distant bridge.
  Generated with the built-in image-generation tool; see [prompt](city-night.prompt.md).
  Center-cropped at runtime for each display aspect ratio.

- `golden-gate-dark.jpg` — Golden Gate Bridge at blue hour, seen from the
  beach below, by
  [Daniel Lloyd Blunk-Fernández](https://unsplash.com/photos/golden-gate-bridge-san-francisco-california-mH9Mz6piRoc)
  on Unsplash (Unsplash License — free to use). Center-cropped and resized
  to 4096x2160 from the 5168x3088 original.
