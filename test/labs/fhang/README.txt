Lab fhang -- a framePr notBeside label holding a 12pt inline picture on an exact 15pt line (Linux lo5, 2026-11-02)
Background: LibreOffice's fdo78904_fileHang (lo-a197b7a8, 21 pages) has "Alert Label" paragraphs: bold, space before 6pt, exact 15pt, framePr wrap=notBeside vAnchor=text hAnchor=text y=1, content = an inline picture 18x12pt then "Note ". Word's print draws the label word 3pt LOWER and the following text 1pt lower than ours; the total height of label + text is the same. We do not know which of picture / exact line / frame decides it.
Every document: Letter, margins 1.25in left/right 1in top/bottom, Arial 10, no compat setting (as the original). Intro paragraph, then the label, then two plain paragraphs (indent 18pt, exact 14pt, 3pt before/after).
Names: -I13 = the paragraph above the label is on an exact 13pt line (as the corpus list item), -L = label indented 18pt; F = framePr notBeside label, N = ordinary paragraph (no frame); 15/20/12/AUTO = exact line pt of the label (AUTO = automatic); P12/P0/P24/P6 = inline picture height pt (P0 = text only); -T = the whole label+text inside a one-cell table.
usage: build.py OUTDIR regenerates docx/. Print each with Word for Windows exactly as the corpus prints are made, then analyze.py PDF-or-DIR > table. Send the table on the branch (FHANG-WORD.tsv).
What matters: note_top/note_bottom and pic_top/pic_bottom against intro_top, and after1_top: how the label's baseline and the text below move with picture height, exact height, frame on/off, table.
