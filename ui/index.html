04 / MAKE YOURSELF AT HOME

Your next desktop.
Start here.

For Ubuntu 26.04 LTS on an Intel or AMD 64-bit PC (amd64). Starling adds a session you can choose at login, alongside your existing desktop.

Full installation guide ↗

  1. Download the desktop

    Open a terminal and download the Ubuntu package:

    curl -fLO https://github.com/starling-build/starling/releases/download/v0.5.0/starling_0.5.0_amd64.deb

  2. Install the package

    In the same folder, install Starling and its dependencies:

    sudo apt install ./starling_0.5.0_amd64.deb

    Ubuntu Desktop includes the login manager. On a minimal or Server install, add it with sudo apt install gdm3.

  3. Sign in to Starling

    Log out, select your name, and open the session menu (usually the gear icon). Choose Starling, then sign in.

Early preview. Tested with AMD, Intel, and NVIDIA graphics, plus VirtIO-GPU / virgl in a VM. See the installation guide for requirements and troubleshooting.
