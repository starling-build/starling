Linux installation steps ↓

All downloads are version 0.1.0. You can choose any platform above.

GET STARTED ON LINUX

Ubuntu & Debian

Open a terminal in your Downloads folder and install the DEB: 

sudo apt install ./starling-office_0.1.0_amd64.deb

Writer, Sheets, and Slides appear in your applications menu.

Flatpak

With Flatpak installed, run these commands from your Downloads folder: 

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./starling-office_0.1.0_x86_64.flatpak
flatpak run build.starling.Office

Flatpak installs the GNOME runtime from Flathub if needed.
