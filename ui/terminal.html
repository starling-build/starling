Build your own

It is a widget. Take it.

The terminal ships in the Starling SDK, so your app can have one too — shell, escape sequences, fonts, scrollback and selection included. A whole terminal app, in full:

main.swift
import ExampleHost
import Flutter

let session = TerminalSession()
session.startShell()

runExampleApp(title: "Terminal", width: 940, height: 620) {
    TerminalView(session: session)
}

The workspace in the films above is that widget with geometry around it — splits, frames and a cover flow, and no terminal code of its own.
